# Portal Guide - Microsoft Foundry ポータルベースの実習

Microsoft Foundry PortalのUIを使用してリソースを作成し管理する実習ガイドです。

## 📖 ポータルベースの実習の特徴

- ✅ **コード作成不要**: Web UIを通じて全ての作業を実行
- ✅ **ビジュアル学習**: 各ステップのスクリーンショットを提供
- ✅ **クイックスタート**: 開発環境設定なしで即座に開始
- ✅ **概念理解**: Foundryの機能と構造を直感的に学習

## 📚 実習モジュール

1. **[環境設定](./01-setup.md)** - Resource GroupおよびFoundryリソースの作成
2. **[モデルとデプロイ](./02-models.md)** - モデルデプロイおよびModel Router構成
3. **[エージェント開発](./03-agents.md)** - 各種エージェントの構築とデプロイ
4. **[Foundry IQ](./04-foundry-iq.md)** - AI Searchおよびナレッジベース構築
5. **[ワークフロー](./05-workflows.md)** - Sequential、Group Chat、Human-in-loopワークフロー
6. **[評価](./06-evaluations.md)** - エージェントパフォーマンス評価
7. **[Control Plane](./07-control-plane.md)** - 運用モニタリングと管理

## 🚀 始め方

1. **[01-setup.md](./01-setup.md)**から順次進めてください
2. 各モジュールのスクリーンショットを参考にPortalで作業してください
3. 前のモジュールで作成したリソースを次のモジュールで活用します

## 💡 次のステップ

ポータル実習を完了した後、[コードベースの実習](../code-guide/README.md)で自動化を学習してください！
